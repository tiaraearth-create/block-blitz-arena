# 🧱 Block Blitz Arena

ブロックブラスト風パズルゲーム — オンライン対戦・AI対戦・ランキング・ショップ・バトルパス・管理者パネルを備えたフルスタック実装です。

![Node](https://img.shields.io/badge/Node.js-%E2%89%A518-green) ![License](https://img.shields.io/badge/license-MIT-blue)

## ✨ 特徴

### ゲームプレイ
- **8×8グリッド** に3つのピースをドラッグ&ドロップで配置し、縦横のラインを消すクラシックなブロックパズル
- ゴーストプレビュー（消えるラインが光って予告）、コンボ&ストリークシステム
- パーティクル爆発・画面シェイク・コンボポップアップ・フローティングスコアなどのリッチな演出
- **WebAudioによる完全合成のBGM/効果音**（音声アセット不要）— 16ステップシーケンサー式の音楽エンジンが**モード別に5トラック**（メニュー/ソロ/バトル/おに/神）を演奏

### モード
| モード | 内容 |
|---|---|
| ▶ ソロプレイ | エンドレスでハイスコアを狙う |
| 🤖 AI対戦 | 2分間のスコアバトル。かんたん/ふつう/つよい の3段階AI（同じピース列で公平勝負） |
| 👹 ??? | **隠し難易度** — 「つよい」に勝利すると解放…他にも解放方法があるとかないとか。勝てば限定バッジ |
| 🔱 ????? | **究極の隠し難易度** — 👹に勝った者だけが辿り着ける。全ピース順列を読み切るビームサーチAI |
| 🌐 1v1 ランクマッチ | WebSocketリアルタイムマッチング。相手の盤面をライブ表示、Eloレート変動。10秒待つとボットが対戦相手に |
| 👥 2v2 チーム戦 | チーム合計スコアで勝負。人数不足はサーバーボットが自動補充（1人でも遊べる） |
| 🔧 カスタムルーム | 4文字コードで友達と対戦。試合時間・1v1/2v2・ボット補充と強さをホストが設定 |

さらに:
- 🔄 **リロール** — 1ゲームに1回、手持ちピースをすべて引き直せる
- 🎁 **デイリーログインボーナス** — 毎日コイン+100・ジェム+5
- ⚙️ **設定** — 効果音/BGMの個別音量、画面シェイクON/OFF、パーティクル量（少なめ/標準/多め）

### メタゲーム
- 👤 **アカウント登録/ログイン**（pbkdf2ハッシュ + Bearerトークン、ゲストプレイも可）
- 🏆 **グローバルランキング**（ハイスコア / PvPレートの2部門）
- 🛍️ **ショップ** — ブロックスキン6種・ボードテーマ5種・消去エフェクト4種（コイン/ジェムの2通貨）
- 🎫 **バトルパス** — 30日シーズン制、30ティア、無料/プレミアムトラック、バッジ報酬
- 🛡️ **管理者パネル** — ユーザー管理（通貨付与・凍結・削除）、全体アナウンス、**シーズン管理（番号/名前/期間の変更・進行維持での巻き戻し対応）**、メンテナンスモード、ランキングリセット、DBバックアップDL、サーバー統計
- 🤖 **オートパイロット（管理者専用）** — 最強AIが自動でプレイ。全モード対応、速度x1/x2/x4切替

## 🚀 起動方法

```bash
npm install
npm start
# → http://localhost:3000
```

初回起動時に **管理者アカウント** が自動生成され、パスワードがコンソールと `server/data/admin-credentials.txt` に出力されます。

```
ユーザー名: admin / パスワード: （コンソール参照）
```

### オンライン対戦を試す
ブラウザのタブを2つ開き、両方で「🌐 オンライン対戦」を押すとマッチングします。

### 環境変数
| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | 3000 | HTTPポート |
| `MATCH_SECONDS` | 120 | オンライン対戦の試合時間（秒） |

## 🏗️ 構成

```
├── server/            Node.js (Express + ws)
│   ├── index.js       REST API（認証/ランキング/ショップ/パス/管理者）
│   ├── battle.js      WebSocket対戦（1v1/2v2/カスタムルーム/サーバーボット）
│   ├── auth.js        pbkdf2認証・トークン管理
│   ├── catalog.js     ショップ/バトルパス定義
│   └── db.js          JSONファイル永続化（依存DBなし）
└── public/            フロントエンド（ビルド不要・素のES Modules）
    ├── js/engine.js   純ロジック（シード付き乱数で対戦の公平性を担保）
    ├── js/game.js     Canvas描画・ドラッグ&ドロップ・アニメーション
    ├── js/particles.js パーティクル（火花/花火/稲妻/桜吹雪）
    ├── js/audio.js    WebAudio合成SFX & ジェネレティブBGM
    ├── js/ai.js       ヒューリスティックAI（穴/断片化評価 + 先読み）
    ├── js/modes.js    ソロ/AI戦/オンライン戦の進行制御
    └── js/screens.js  ランキング/ショップ/パス/管理画面
```

## 🌍 公開する（デプロイ）

### 1. GitHubへプッシュ
```bash
git remote add origin https://github.com/<あなたのユーザー名>/block-blitz-arena.git
git push -u origin master
```

### 2. ホスティング（無料枠で可）
**Render** (おすすめ・簡単):
1. [render.com](https://render.com) で「New → Web Service」→ GitHubリポジトリを接続
2. Build Command: `npm install` / Start Command: `npm start`
3. 「Disks」で永続ディスクを追加し、Mount Path を `/opt/render/project/src/server/data` に（セーブデータ保持のため）

**Railway / Fly.io** も同様（`PORT` は自動注入、対応済み）。**Docker** も可:
```bash
docker build -t block-blitz .
docker run -p 3000:3000 -v blockblitz-data:/app/server/data block-blitz
```

### 3. 公開後の注意
- 初回起動ログ（またはディスク内の `server/data/admin-credentials.txt`）から**管理者パスワードを控えて保管**
- HTTPSはホスティング側が終端します（クライアントは自動で `wss://` を使用）
- 認証エンドポイントにはレート制限（20回/5分/IP）を内蔵
- 更新をデプロイする前に管理者パネルの「🛠 メンテナンス」→「💾 バックアップDL」の利用を推奨

## 🔒 セキュリティ / 公平性
- パスワードは pbkdf2(12万回) + ソルトでハッシュ化
- スコア送信はサーバー側でレート上限チェック（チート対策）
- 対戦は同一シードのピース列を両者に配布して公平化
- 管理者APIはロールベースで保護
